# Order Notification Service

The **Order Notification Service** exposes a **SignalR hub** to deliver real-time workflow updates to the SPA.

It subscribes to `OrderProcessed` events and pushes status changes to the right user/session using Redis as an ephemeral registry.

## Local endpoints (Docker Compose)

- HTTP: `http://localhost:5006`
- HTTPS (recommended): `https://localhost:5007`
- Health: `/healthz` (and `/health/live`, `/health/ready`)
- Dev token: `POST /dev/token` `{ "userId": "CUST-0001" }`
- Hub:
  - `/hubs/order-status`
  - `/hubs/order-status/negotiate`

> Local HTTPS uses a dev certificate generated by `./infra/local/ensure-devcert.sh` (or `.ps1` on Windows).
